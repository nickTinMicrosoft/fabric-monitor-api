# Azure Monitor Metrics

[Home](../README.md)

## Summary

Metrics are numeric time-series values emitted by Azure resources, such as CPU or utilization. The metrics API retrieves values and the metric definitions API lists which metrics a resource supports. These pages are generic and do not mention Fabric.

|------|------|------------------|
