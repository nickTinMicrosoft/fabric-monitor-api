# Azure Activity Logs and Diagnostic Settings

[Home](../README.md)

## Summary

The activity log records control-plane events on Azure resources, such as who created or changed a resource. Diagnostic settings route a resource's platform logs and metrics to Log Analytics, storage or Event Hubs. These pages are generic and do not mention Fabric.
