## Summary

Azure Monitor is the umbrella platform for telemetry across Azure resources. It collects metrics, logs and activity data, and provides alerting. These pages are generic and do not mention Fabric. They matter for Fabric only where a Fabric capacity (an Azure resource) sends data to Azure Monitor.

This page links the API reference and index. See the other pages for each area:

- [Metrics](azure-monitor-metrics.md)
- [Logs](azure-monitor-logs.md)
- [Activity logs and diagnostic settings](azure-activity-and-diagnostics.md)
- [Alerts and action groups](azure-monitor-alerts.md)
