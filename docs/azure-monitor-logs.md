# Azure Monitor Logs and Log Analytics

[Home](../README.md)

## Summary

Azure Monitor Logs stores log data in Log Analytics workspaces. You query it with KQL through the Logs Query API or the Log Analytics REST APIs, and you send custom data in through the Logs Ingestion API. These pages are generic and do not mention Fabric.
