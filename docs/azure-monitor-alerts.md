# Azure Monitor Alerts and Action Groups

[Home](../README.md)

## Summary

Scheduled query rules run log queries on a schedule and raise log alerts. Action groups define who is notified and which actions run, such as email, webhook or automation. These pages are generic and do not mention Fabric.
